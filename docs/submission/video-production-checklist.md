# Lantern submission video production checklist

Use this checklist for the exact public 1–3 minute Congressional App Challenge demonstration. The target is 2:45–2:55.

## Before recording

- [ ] Record from the exact release candidate intended for submission.
- [ ] Confirm `/`, `/first-day?demo=1`, `/privacy`, and `/first-day/how-it-works` return successfully on the public deployment.
- [ ] Open a clean browser profile with no personal bookmarks, history suggestions, saved accounts, extensions, or notifications visible.
- [ ] Hide the bookmarks bar and close unrelated tabs and applications.
- [ ] Confirm no environment variables, API keys, terminal history, private URLs, or developer tools will appear.
- [ ] Set the capture canvas to at least 1440×900 and verify text remains readable after upload compression.
- [ ] Use a visible but unobtrusive cursor and disable cursor effects that cover source text.
- [ ] Silence system and phone notifications.
- [ ] Select **Reset demo** and confirm Beat 1, two facts to check, and one blocker.
- [ ] Complete one full English rehearsal including the automatic Decision Trace.
- [ ] Complete one Spanish-switch rehearsal through **Llevar conmigo**.
- [ ] Monitor requests during rehearsal and confirm the fictional judge path makes no provider request.
- [ ] Test the microphone at the same distance and input level used for the final take.
- [ ] Read the script aloud with a timer; target 2:45–2:55 without rushing.

## Required spoken content

- [ ] “Isaac Gong.”
- [ ] “Lantern: First Day.”
- [ ] The purpose sentence.
- [ ] Newcomer families as the target audience.
- [ ] Next.js, React, TypeScript, Zod, Vitest, and Playwright.
- [ ] Working functionality, not static mockups.
- [ ] Runtime AI boundary and human decision role.
- [ ] Synthetic nature of the evaluation metrics.

## Required visual proof

- [ ] Fictional-data label and three separate document identities.
- [ ] Exact source quote linked to a fact.
- [ ] Two unanswered family questions.
- [ ] Both conflicting orientation sources.
- [ ] School-reported Gym entrance resolution.
- [ ] Focused update showing only the dependent task changed.
- [ ] Decision Trace stages and final Ready state.
- [ ] Spanish family plan and export actions.
- [ ] Engineering proof panel, tool list, metrics, and limitations.

## Take acceptance

- [ ] Duration is between 1:00 and 3:00; preferred duration is 2:45–2:55.
- [ ] Speech is clear, paced, and free of clipped words.
- [ ] App text and source quotations are readable at normal playback size.
- [ ] Every shown transition occurred in the working app.
- [ ] No edit combines states in a way that misrepresents product behavior.
- [ ] No real family data, secrets, personal notifications, or private browser information appears.
- [ ] No claim implies district partnership, family validation, or real-world outcome evidence.
- [ ] The app name, dates, locations, counts, and selected answer are consistent throughout.

## Publication

- [ ] Add accurate captions and review every technical term and number.
- [ ] Create a transcript from the actual final take.
- [ ] Upload to YouTube or Vimeo with **public** visibility, as required by the 2026 CAC rules.
- [ ] Test the link in a signed-out/private browser window.
- [ ] Confirm playback does not require permission or an account.
- [ ] Record the final video URL, duration, publication state, transcript path, commit, tag, and deployment in `submission-manifest.md` only after each exists.
